# Breez SDK - Liquid

For new partners looking to add instant, non-custodial bitcoin and stablecoins to their apps or services, we recommend building with the **[Breez SDK - Spark](https://sdk-doc-spark.breez.technology/)**.

For existing partners building with the Breez SDK - Liquid, we recommend moving to the [Breez SDK - Spark](https://sdk-doc-spark.breez.technology/) as soon as possible.

This repository builds the single page served at
https://sdk-doc-liquid.breez.technology

## Build

```bash
cargo install mdbook
mdbook build
```
